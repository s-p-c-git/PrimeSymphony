# PrimeSymphony — Claude Code Context

## What this project is

Computational number theory research by S. Chakravarthy. The primary published
contribution is in `shifted-prime-tension/` — a study of the shifted-prime
tension function T_k(p) = 1/spf(p+k) and its classification via quadratic field
splitting, with Dirichlet series decomposition and spectral verification.

## Key mathematical facts (for context when reading the code)

- `S_k(q) = {p prime : spf(p+k) = q}` — the limit-q class of shift k
- For even k and prime q, this class satisfies `p ≡ −k (mod q)` and splits in
  Q(√d_q) iff `(−k mod q)` is a quadratic residue mod q (Euler criterion).
- The central identity `(d_q/p) = (a/q)` for prime `p ≡ a (mod q)` was verified
  against thousands of primes for q = 3,5,7,11,13,17,19.
- Canonical case k=2: limit orphans = primes ≡ 1 (mod 3) = primes splitting in
  Z[ω] (Eisenstein integers). Their generating series factors through
  ζ_{Q(√−3)}(s) = ζ(s)·L(s,χ₋₃).
