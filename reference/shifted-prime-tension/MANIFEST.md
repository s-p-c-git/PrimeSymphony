# Bundle Manifest

Generated package for the `shifted-prime-tension` subproject of PrimeSymphony.
Drop the `shifted-prime-tension/` directory into the root of your local
PrimeSymphony clone.

## Files

### Documentation
- `README.md` — project overview, result table, reproduction commands
- `requirements.txt` — Python dependencies
- `MANIFEST.md` — this file
- `CLAUDE_CODE_INSTRUCTIONS.md` — paste-ready prompts for Claude Code

### Source (src/)
- `_paths.py` — portable path config (data/ and figures/ relative to project)
- `step0_sieve_and_classify.py` — sieve 10^7, verify Theorem 3.3 + Corollary 3.5
- `step1_classification_table.py` — T_k (k,q) table + period-6 law (self-contained)
- `step2_density_mcmc.py` — density convergence + MCMC decay-exponent fit
- `step3_fft_spectrum.py` — error-term FFT + L(s,χ₋₃) zeros + peak matching
- `step4_turing_box.py` — RIGOROUS winding-number zero count (Theorem 5.2)
- `step5_newton_pipeline.py` — FFT-seeded Newton refinement to machine precision

### Figures (figures/) — regenerated by the scripts; included for reference

- `spectrum.png` — from step3

## One bug fixed during packaging

The original `step1` used sympy's `legendre_symbol` with a prime representative,
which raised on certain (k,q). Replaced with a direct Euler-criterion test of
`(a/q)`, after verifying `(d_q/p) = (a/q)` across thousands of primes for
q=3,5,7,11,13,17,19. The mathematics is unchanged; the implementation is now
correct and dependency-light.
